## 🚀 How to Run Locally

You can run this portfolio locally with any static web server:

### Option 1: Python
```bash
cd "C:\Users\santh\.gemini\antigravity-ide\scratch\sriram-portfolio"
python -m http.server 3000
```
Then open: [http://localhost:3000/](http://localhost:3000/)

### Option 2: Node.js (npx serve / live-server)
```bash
cd "C:\Users\santh\.gemini\antigravity-ide\scratch\sriram-portfolio"
npx serve .
```

### Option 3: Direct Browser
Simply double-click `index.html` in your file explorer to open it in Chrome, Edge, or Firefox!

## 🌐 Deploying to Vercel / GitHub Pages

- **Vercel**: Run `npx vercel` inside the folder or import the repository on vercel.com.
- **GitHub Pages**: Push this directory to your GitHub repository (`github.com/srixram08/portfolio`) and enable GitHub Pages under Settings → Pages.
